# Empirical_models_EAS_GDT
Empirical models for Effective Amplitude and Fourier Phase Spectra of ground motions recorded in the Chilean Subduction Zone

The database comprises the strong ground motion data and metadata used in the article under review:

**''Empirical models for Effective Amplitude and Fourier Phase Spectra of ground motions recorded in the Chilean Subduction Zone'' by Osses-Valenzuela et al.**

Structure:
Summary (Resumen) with each seismic record (4134) considering their different columns (c) 
- c1: ID
- c2: Event name
- c3: Station
- c4, c5, c6, c7, c8, c9: Year, Month, Day, Hour, Min, Seg of each event
- c10, c11, c12, c13: Latitude, Longitude, Magnitude, and Depth of each event
- c14, c15, c16: Latitude, Longitude, and Elevation of each station
- c17, c18, c32: Vs30, f0, and A0 at each station
- c26, c31: Hypocentral distance and event-type (interface or inslab).
